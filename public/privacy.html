What we collect

When you submit a request, we store your email address, website URL, platform, issue description, referral source, request ID, conversation messages and submission time. A private conversation link lets anyone who has it read and reply to that request. Keep it safe. We send a copy of the link using Resend; email is for notifications, while discussion happens on this website. We use this information to evaluate your request, contact you about it and deliver an agreed service. Please do not submit credentials, sensitive personal information or other people’s private data.

If you reply by email to onefix@remontoire.ai, Cloudflare routes the message into our private queue. We retain sender and reply headers, subject, text (or HTML source for an HTML-only message), receipt time and attachment count for up to 30 days. Attachments are omitted; use the private website conversation to share reproduction and code links. Email does not create a paid order or prove authority over a request.

Hosting and abuse prevention

The site and request database run on Cloudflare. Cloudflare processes network data to host and protect the service. To limit repeated submissions, the application stores an hourly hash derived from your IP address and removes it after its short expiry. We also record the submission event and its referral source. We do not use advertising cookies or sell your information.

AI coding tools assist with evaluation and code changes. Only send code and descriptions you have permission to share. Before sharing private source code, discuss any confidentiality requirements with us. We do not ask for production passwords in the request form.
