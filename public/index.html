A few things to know.

What exactly does €49 cover?

One reproducible frontend issue with an agreed outcome, such as fixing an overlapping mobile header or a broken JavaScript toggle. We inspect the request first. If it’s too large, we say so before taking payment.

Who does the work?

One Fix is an experiment operated by Dave (GitHub: davedx). AI coding agents assist with diagnosis and implementation. We disclose the changes and checks in your deliverable so you can review them before deploying. You can also inspect our own service implementation and browser tests. This is an example of our work, not a past client project.

Do you need access to my website?

We need the relevant source code and reproduction steps after we agree the scope. A minimal example or repository access is often enough. Never submit production passwords here. Deployment is your decision.

When do I pay?

After we confirm the scope and delivery time in your private conversation, we send a secure payment link. Submitting this form costs nothing and creates no payment obligation.

What if the fix doesn’t work?

We make one correction against the agreed scope. If we cannot deliver that scope, we refund the €49. If we miss the agreed delivery time, you can cancel for a full refund before delivery.
